# Distribute public APK downloads initially

The initial public Android release will be distributed through APK downloads rather than Google Play. Compatible application changes will use EAS Update, while changes that require another native build will need another APK release. Google Play distribution can be reconsidered later, and the signing setup remains to be selected.

On November 13, 2026, the user explicitly requested making the existing source repository public instead of creating a separate distribution repository. The repository is now public and can host APK release assets at [Tauqeer-Ahmed-99/hajj-and-umrah-travel-checklist](https://github.com/Tauqeer-Ahmed-99/hajj-and-umrah-travel-checklist). Publishing an APK remains part of the later build and release work.
